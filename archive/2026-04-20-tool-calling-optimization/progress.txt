## Codebase Patterns
- `_build_prompt()` 中的 `tool_definitions` 现在优先从 category YAML 读取，fallback 到全局 `TOOL_DEFINITIONS_TEXT`
- `tool_definitions` 字段在 YAML 中不需要双写花括号转义，因为它作为完整字符串注入 meta_prompt，不经过 `.format()` 处理
- `meta_prompt` 中的 JSON 花括号必须双写转义（`{{` 和 `}}`），否则 Python `.format()` 报 KeyError
- 新增 subcategory 会自动参与 `generate_via_llm()` 的 round-robin 轮转
- seed 样本必须是单行合法 JSON，每条用 `\n` 分隔
- 并行工具调用样本中，assistant 消息的多个 `<tool_call>` 块之间用 `\n\n` 分隔
- 对应的 user 消息中包含多个 `<tool_response>` 块，用 `\n\n` 分隔
- `todo_write` 的 tool_response 返回 JSON 格式的 todo 列表快照

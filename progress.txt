## Codebase Patterns
- 样本类型定义使用 data/categories/*.yaml 文件，load_categories() 自动扫描加载
- 种子数据使用 data/seeds/*.jsonl 文件，每行一个 JSON 对象，包含 messages + metadata
- metadata 结构：{"category": "xxx", "subcategory": "xxx", "difficulty": "basic|intermediate|advanced"}
- system 提示词定义在对应的 YAML meta_prompt 中，种子数据的第一条 message 也必须是 system role
- config/config.yaml 中的 category_ratios 定义各类型生成比例，总和为 1.0
- generate_data.py 中有两处硬编码默认比例（--merge 模式和 LLM 生成模式），修改类型时需同步更新
- train.py 的 _infer_category() 用内容关键词推断类别，添加新类型需在此函数增加检测逻辑
- test_model.py 中每个类型有对应的 test_xxx() 评估函数，evaluate_model() 汇总所有维度
- extract_seeds.py 已简化为种子文件验证工具（不再从 generate_data.py 提取）
- config.yaml 被 .gitignore 忽略，需要 git add -f 强制添加
